# Repository Guidelines

## Materials Page Maintenance

- When new PPT, PPTX, PDF files, or cover images are added, check whether a new Materials entry should be created.
- Read the actual slide or report content before writing the description or keywords.
- Use restrained academic language.
- Avoid promotional wording and overclaiming.
- Do not hallucinate missing metadata.
- Use `TODO:` for uncertain fields.
- Preserve the existing Jekyll/al-folio structure and visual style.
- Do not change unrelated pages.
